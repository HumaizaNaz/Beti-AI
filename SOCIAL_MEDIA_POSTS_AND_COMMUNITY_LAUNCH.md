## 🛠️ 5. Step-by-Step: GitHub par Code Push Karne Ka Tariqa

Apne computer par Terminal / Command Prompt kholen aur yeh 5 lines run karein:

```bash
# Step 1: Git repository initialize karein
git init

# Step 2: Saari files add karein
git add .

# Step 3: Pehla commit banayein
git commit -m "feat: Initial commit for Project Beti Multi-Agent Safety System"

# Step 4: Branch main set karein
git branch -M main

# Step 5: Apni GitHub repo ka link lagayein aur push karein
git remote add origin https://github.com/YOUR_USERNAME/beti-ai.git
git push -u origin main
```
